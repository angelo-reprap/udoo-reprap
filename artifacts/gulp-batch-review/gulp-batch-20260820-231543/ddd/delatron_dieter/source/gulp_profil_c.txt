 05/08 - 11/08
 Projekt: Providermanagement
 Kunde: EDS Itellium Nürnberg
 Im Projekt Providermanagement (Teilprojekt Mandantenvorbereitung)
werden grundsätzlich alle Funktionalitäten angepasst welche,
 die Mandantenfähigkeit betreffen und die es ermöglichen einen
Mandanten auf verschiedenen Ebenen innerhalb der logistischen Systeme
Primondo produktiv zu setzen.
 Tätigkeit: Erzeugen Packages mit PL/SQL, entwickeln Forms mit Forms
Builder,
 Anlegen Tabellen, Index, Indices, Trigger, Synonyme usw.
 Systemumfeld: Oracle 10g, Forms Builder Version 10.1.2.0.2, TOAD 9.1,
PVCS (Serena ChangeMan Version Manager V.8.1.2), Sybase PowerDesigner

 09/07 - 04/08
 Projekt: New Features 1
 Hostablösung Auftragsschreibung / Bedarfsüberwachung
 Kunde: EDS Itellium Nürnberg
 Beschreibung: Migration Cobol / Assembler Programme nach Oracle
PL/SQL.
 Das Projekt "New Features Stufe 1" ist Teilprojekt des Projektes "New
Features WaWi Host Ablösung" das zum Ziel hat,
 die warenwirtschaftlichen HOST Programme in die Systeme der EASY
Systemlandschaft zu überführen,
 damit diese später auf dem Host abgeschaltet werden können. New
Features besteht aus 6 Teilprojekten, die "Stufen" genannt werden.
 Die Stufe 1, zu der der hier beschriebene Themenkomplex gehört,
beschäftigt sich mit folgenden Bereichen:
 - Transport Dispo / EDIFACT
 - Import Export Routinen und Pflegemasken
 - Schnittstellen/Prima Integration/ DBTABDAT Ablösung
 - Listen / Reports, Dispo-Ablösung und Bonus Ausschöpfung
 - Listen und Schnittstellen im Umfeld Orderbestand /WE
 - Bedarfsüberwachung / Disposition
 Es werden nur die noch aktiven und relevanten Host Programme
migriert. Dabei sind grundsätzlich keine funktionalen Erweiterungen
vorgesehen,
 lediglich die 4 Konzepte des Projektes QKey (Schlüsselerweiterungen)
werden berücksichtigt.
 Tätigkeit: Fach- und IT Konzeption, Erzeugen Packages mit PL/SQL,
entwickeln Forms mit Forms Builder,
 Anlegen Tabellen, Index, Indices, Trigger, Synonyme usw.
 Systemumfeld: Oracle 10g, Forms Builder Version 10.1.2.0.2, TOAD 9.1,
PVCS (Serena ChangeMan Version Manager V.8.1.2)

 06/04 - 08/07
 Prjekt: Stammdatenverwaltung
 Kunde: europet Benelux Nürnberg
 Stammdaten (Adressen, Kunden, Lieferanten, Vertreter, Artikel) werden
über eine Java-Oberfläche verwaltet.
 Die Daten werden aus der Produktions-DB (Informix) in eine MS-SQL
Server DB übernommen.
 Mit dem Java Programm sind Neuanlagen, änderungen sowie Löschungen
über spezielle Berechtigungen möglich.
 über individuelle Selektionskriterien werden die Auswertungen im
PDF-Format erstellt (mit iText).
 Mit dem Programm können die Listen per Adobe Reader gelesen, gedruckt
sowie via Email versendet werden.
 Der Einsatz dieser neuen Benutzeroberfläche ist auf einem
Linux-Server vorgesehen.
 Systemumfeld: Windows XP, Java, Borland JBuilder X, iText, MS
SQL-Server.

 11/03 - 05/04 
 Projekt: Infosystem
 Informationssystem für Messeauftritt sowie Katalog (auf CD).
 Kunde: europet Benelux Nürnberg
 Die verschiedenen Produktbereiche können über Buttons ausgewählt und
Detailinformationen abgerufen werden.
 Die Messeversion holt die Daten aus einer SQL-Server DB und die
CD-Version arbeitet mit internen Dateien.

 Das Systemfeld bestand aus den Komponenten: Windows XP, Java, Borland
JBuilder X, Informix und MS SQL-Server.
