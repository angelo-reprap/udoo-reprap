Microsoft System Center

Verwaltung von Data Centern mit einem oder mehreren Standorten.

Konzepten betrachtet und konfiguriert.
 
System Center Configuration Manager
Design und Aufbau sowie Migration verschiedener Configuration Manager
Infrastrukturen mit Central Administration Site oder eigenständiger Primary
Site zur Verwaltung von Windows Clients als auch Windows Servern. Die Anzahl zu
verwaltender Clients und Server lag zwischen 500 und 130.000 Systemen. Die
Systeme waren verteilt über bis zu 250 weltweite Standorte.
 
System Center Operations Manager
Design und Aufbau sowie Migration verschiedener Operations Manager Management
Groups. Die Anzahl zu verwaltender Server betrug bis zu 7.000 Windows und Linux
Systemen sowie Netzwerk Geräten. Die Systeme befanden sich in Data Centern und
bis zu 250 weltweiten Standorten.

erstellt.
 
System Center Orchestrator / Service Management Automation

Implementierung automatisierter Prozesse. Dabei wurde der Orchestrator mit den
System Center Produkten SCCM, SCOM, SCVMM und SCSM sowie VMware vSphere und
Service Now verbunden. Implementiert wurden beispielsweise Runbooks zur
automatisierten Server Bereitstellung oder zum Software Update Management.

03/2017 - 12/2018: Server Management mit System Center
 
Einsatzort:         Köln
Rolle:              Architekt, Senior Consultant
Kunde:              Dienstleiter
 
Aufgaben:
 
Ablösung einer bestehenden Configuration Manager Infrastruktur durch
Configuration Manager Current Branch zur Verwaltung der weltweiten Server
Systeme.
Wesentliche Funktion ist die Implementierung eines weltweit einheitlichen
Software Update Managements mit einem möglichst hohen Maß an Automatisierung.
 
Im zweiten Schritt wird System Center Orchestrator eingeführt. Damit sollen
weitere Schritte zur Automatisierung von Prozessen unterstützt und
implementiert werden, zum Beispiel das automatisierte Software Update
Management von AlwaysOn und Cluster Systemen oder verbundenen Systemen mit
komplexen Abhängigkeiten.
 
Als dritter Schritt ist die Implementierung von System Center Operations
Manager zur Überwachung der Windows Server geplant.
 
Insgesamt sollen die Produkte SCCM, SCO und SCOM gemeinsam und im Zusammenspiel
die administrativen Standardaufgaben automatisieren sowie den individuellen
administrativen Aufwand optimieren und reduzieren.
 
Kenntnisse:
 
SCCM, SCOM, Orchestrator
