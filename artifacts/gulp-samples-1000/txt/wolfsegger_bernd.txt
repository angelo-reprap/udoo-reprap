	Die Website wird mit einem Java basierten Content Management System

	Die Daten aus zahlreichen Formularen für Berechnungen und

	Ich war bei diesem Projekt für die vollständige technische Konzeption

Ansprechpartner für den Kunden. 

	Da die verwendete Java CMS Software leider zum damaligen Zeitpunkt
viele Schwächen aufwies, nicht sehr performant war, sehr fehlerhaft
war in vielen Bereichen, und es außerdem an bestimmten nötigen
Features mangelte, bestand meiner Aufgabe neben der Realisierung der
Site darin, eine Schnittstelle zur CMS API zu entwickeln, welche die
Performance durch ein eigenes Caching System signifikant verbesserte,
Fehler abfing, die Entwicklung von JSPs wesentlich vereinfachte und
fehlende Features ergänzte. 

	Es entstand eine komplette API, so das bei der Entwicklung der
Projekt spezifischen Klassen und JSPs / Servlets nicht mehr auf die
schlecht dokumentierte und organisierte API des CMS Systems
zurückgegriffen werden musste. 

	Diese API wurde für alle drei Folgeprojekte (siehe weiter unten) mit
dem gleichen CMS System eingesetzt. 

	Für den Datenaustausch zum Intranet wurden für jedes Formular XML
Schemas erstellt und entsprechende Java Klassen mittels Castor
generiert. Das weitere Handling der Daten für den Versand konnte
dadurch transparent wie gewohnt mittels Java Getter und Setter
Methoden erfolgen.

	Die Daten die in diesen Tools zu verarbeiten waren, wurden in einer

	Die auf der Extranet Site präsentierten Daten lagen nur im Intranet
