	 JBoss 4, Maven, Serena Dimensions Beschreibung:
 Mit Couponing an der Kasse können in einer Filiale basierend auf der
Einkaufshistorie und dem aktuellen Warenkorb eines Kunden

 Das Software System besteht aus den Kassen und einem Server in den
Filialen, die über eine WebService Schnittstelle mit dem
Couponing-Server kommunizieren. Der Couponing-Server hat wiederum eine

Data Warehouse. Diese Daten werden dann in den Couponing-Server
importiert und dienen als Grundlage für die Auswahl der Tickets,
sobald Online-Anfragen über die WebService Schnittstelle von dem
Filial-Server ankommen. Von Zeit zu Zeit werden dann Informationen
über die ausgedruckten Tickets und die Warenkörbe wieder in das Data
Warehouse exportiert und stehen somit für die nächste Vorauswahl zur
Verfügung.

 Projekt: LMS (Loyalty Management System) Batch Job Framework
 Auftraggeber: LMS Produktentwicklung
 Zeitraum: 01/06 bis 08/06
 Rolle: Architekt, Entwickler
 Technologien: Java 5, JMX, JMS, AspectJ, Spring, Hibernate, AndroMDA,
Oracle 10g,

	 Mule ESB, Velocity, Maven, Serena Dimensions, Quartz Beschreibung:
 Entwicklung eines hochskalierbaren Frameworks zur Abarbeitung
langlaufender Jobs mit umfangreichem Monitoring und ausgeklügelten
Fehlerhandling.
 Die Jobs werden in Tasks unterteilt, die parallel ausgeführt werden
können. Der Ablauf eines Jobs wird in der Datenbank gespeichert, so
dass jederzeit der Fortschritt und die Anzahl der Fehler eines Jobs
verfolgt werden können. Des Weiteren lassen sich diese Informationen
nutzen um Jobs im Fehlerfall wieder anstarten zu können.
 Das Job Framework wurde für verschiedene Arten von Jobs eingesetzt
und spezifisch erweitert, wie z.B. für den Datei-Import und
Datei-Export.
 Durch den Einsatz des Job Frameworks konnten selbst große Dateien
parallel verarbeitet werden. Sowohl beim Import als auch beim Export
können unterschiedliche Dateitypen wie z.B. XML, CSV oder Flat-Files
importiert bzw. exportiert werden. Beim Import werden konfigurierbare
Parser eingesetzt und beim Export konfigurierbare Renderer, die
basierend auf einer Datei-Formatbeschreibung die unterschiedlichen
Dateitypen verarbeiten.
 Am Ende der Verarbeitung wird eine Ergebnis-Datei erstellt, die
Auskunft über den Erfolg und die aufgetretenen Fehler beim Import
gibt.

Projekt: LMS (Loyalty Management System) Batch Job Framework
Auftraggeber:     LMS Produktentwicklung
Zeitraum:         01/06 bis 08/06
Rolle:           Architekt, Entwickler
Technologien:     Java 5, JMX, JMS, AspectJ, Spring, Hibernate, AndroMDA, Oracle 10g,

 Mule ESB, Velocity, Maven, Serena Dimensions, QuartzBeschreibung:
Entwicklung eines hochskalierbaren Frameworks zur Abarbeitung langlaufender Jobs mit umfangreichem Monitoring und ausgeklügelten Fehlerhandling.
Die Jobs werden in Tasks unterteilt, die parallel ausgeführt werden können. Der Ablauf eines Jobs wird in der Datenbank gespeichert, so dass jederzeit der Fortschritt und die Anzahl der Fehler eines Jobs verfolgt werden können. Des Weiteren lassen sich diese Informationen nutzen um Jobs im Fehlerfall wieder anstarten zu können.
Das Job Framework wurde für verschiedene Arten von Jobs eingesetzt und spezifisch erweitert, wie z.B. für den Datei-Import und Datei-Export.
Durch den Einsatz des Job Frameworks konnten selbst große Dateien parallel verarbeitet werden. Sowohl beim Import als auch beim Export können unterschiedliche Dateitypen wie z.B. XML, CSV oder Flat-Files importiert bzw. exportiert werden. Beim Import werden konfigurierbare Parser eingesetzt und beim Export konfigurierbare Renderer, die basierend auf einer Datei-Formatbeschreibung die unterschiedlichen Dateitypen verarbeiten.
Am Ende der Verarbeitung wird eine Ergebnis-Datei erstellt, die Auskunft über den Erfolg und die aufgetretenen Fehler beim Import gibt.
